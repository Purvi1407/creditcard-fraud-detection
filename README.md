# 💳 AI Fraud Detection System

AI-powered fraud detection web application built using Python, Streamlit, and Machine Learning to identify suspicious banking transactions in real-time.

---

# 🚀 Features

* 🔍 Real-time transaction fraud detection
* 📊 Dynamic fraud risk score analysis
* 🤖 Machine Learning powered predictions
* 💳 Interactive fintech-style dashboard
* 🛡️ Fraud alerts and suspicious activity detection
* 📈 Model performance metrics
* 🧾 Transaction summary generation
* 🎨 Modern responsive UI design

---

# 🛠️ Tech Stack

### Frontend

* Streamlit

### Backend / ML

* Python
* Scikit-learn
* Random Forest Classifier

### Libraries Used

* Pandas
* NumPy

---

# 📊 Machine Learning Model

The project uses a **Random Forest Classifier** trained on credit card transaction data to identify potentially fraudulent transactions based on transaction behavior patterns.

The model evaluates:

* Transaction Amount
* Transaction Type
* Transaction Location
* Transaction Time
* Device Usage

to calculate fraud probability and risk levels.

3. Risk score is calculated
4. Fraud detection result is generated
